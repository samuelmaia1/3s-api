Metodologia e Ferramentas

  • Framework de testes: JUnit 5 (Jupiter) com anotações @Test, @BeforeEach
  • Mocking: Mockito 5 com @Mock, @InjectMocks, @ExtendWith(MockitoExtension.class) — todas as dependências externas (repositórios, WebSocket) foram simuladas com mocks para isolar a lógica de negócio
  • Cobertura: JaCoCo 0.8.12 integrado ao Maven — relatório gerado automaticamente após mvn test
  • Escopo da cobertura: Camada de domínio (regras de negócio puras). Serviços de infraestrutura (JPA, geração de PDF, WebSocket) foram excluídos da métrica, pois requerem testes de integração com banco de dados — prática padrão em desenvolvimento enterprise
  • Tipos de teste: Testes unitários (TU) — cada classe testada de forma isolada, sem dependências reais
  • Resultado: 169 casos executados, 0 falhas, cobertura de 71,06% de linhas e 69,95% de métodos

Descrição do Software Testado

  • Nome: 3S API — API REST de gestão empresarial para a empresa 3S Letreiros
  • Tecnologias: Java 21, Spring Boot 4.0.1, PostgreSQL, JWT, WebSocket (STOMP)
  • Total de classes/arquivos no projeto: ~90 classes Java
  • Classes no escopo de teste (domínio): 69 classes medidas pelo JaCoCo
  • Métodos totais no escopo: 183 métodos
  • Principais funcionalidades: Gestão de usuários, produtos com estoque, clientes, pedidos de venda, aluguéis com validação de período, contratos com cláusulas customizáveis, geração de PDF, dashboard gerencial e notificações em tempo real via WebSocket
